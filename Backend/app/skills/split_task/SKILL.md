## 技能定位

`split_task` 是 FocusPet 内部 Pet Agent Skill，不是 Codex 插件技能。

它只负责生成结构化建议，不直接创建、编辑、删除、完成任何用户数据。iOS 端必须把结果展示给用户，由用户勾选并点击确认后，才可以写入待办。

## 输入

- `user_input`: 用户原始目标或任务描述
- `pet_type`: 当前宠物类型，用于拼接宠物人设 prompt

## 输出

严格返回：

```json
{
  "tasks": ["步骤1", "步骤2", "步骤3"]
}
```

输出要求：

- 只输出中文
- 3 到 5 条
- 每条是一句完整的话
- 每条都要具体、低门槛、能马上开始
- 优先使用“打开、整理、列出、写下、查找、确认、完成初稿”等动作
- 不输出鼓励语、总结语或泛泛建议

## 触发条件

明确触发：

- 用户说“帮我拆任务”
- 用户说“拆一下”
- 用户说“把这个分成几步”

需要先确认再触发：

- 用户说“我不知道怎么准备”
- 用户说“这件事不知道怎么做”
- 用户只表达目标过大，但没有明确要求拆解

不触发：

- 自伤、自杀、违法、暴力、危险、健康透支输入
- 纯闲聊
- 用户只是想记录备忘
- 用户只是询问下一步先做哪个
- 用户只是要求复盘最近状态

## 执行流程

1. `input_guard` 先做安全审核。
2. 审核不通过时，直接拒绝进入 skill。
3. API key 缺失或 LLM 请求失败时，使用 `fallback.py` 的本地模板。
4. API key 可用时，拼接：
   - 全局产品边界
   - 当前宠物人设
   - `prompt.py` 中的拆任务规则
   - 当前用户输入
5. 严格解析 JSON。
6. 返回待用户确认的任务列表。

## 边界原则

- 只提供候选任务，不写入待办。
- 不直接开始专注。
- 不替用户确认“全部加入”。
- 不把抽象人生目标拆成宏大计划，要先缩小到近期可执行动作。
- 如果目标太大，优先生成最近能做的一小段，而不是完整人生规划。
