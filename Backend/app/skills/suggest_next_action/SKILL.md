## 技能定位

`suggest_next_action` 是 FocusPet 内部 Pet Agent Skill，不是 Codex 插件技能。

它只负责建议“下一小步”，不替用户开始专注，不修改任务，不自动完成任务。前端可以把建议专注时长带到专注设置页，但必须由用户主动点击开始。

## 输入

- `task`: 后端规则已经选中的单个任务摘要
- `pet_type`: 当前宠物类型，用于拼接宠物人设 prompt
- `reason`: 后端选择该任务的确定性理由
- `suggested_focus_minutes`: 建议专注分钟数

## 输出

结构化返回：

```json
{
  "task_id": "task-id",
  "action": "可以先把「整理项目案例」往前推进一点点。",
  "reason": "它已经有一点进展，继续成本更低。",
  "suggested_focus_minutes": 15
}
```

## 触发条件

明确触发：

- 用户说“我先做哪个”
- 用户说“下一步做什么”
- 用户说“不知道先做什么”
- 用户说“从哪开始”

不触发：

- 用户明确要求拆任务
- 用户明确要求复盘
- 用户只是记录备忘
- 自伤、自杀、违法、暴力、危险、健康透支输入

## 执行流程

1. Pet Agent 先做安全审核。
2. Pet Agent 根据当前任务列表确定候选任务。
3. Skill 只围绕这一个任务生成一句具体下一步。
4. API key 缺失或 LLM 请求失败时，使用 `fallback.py`。
5. 返回结构化建议给前端展示。

## 边界原则

- 只建议一个动作，不给多个选项。
- 不直接开始专注。
- 不替用户确认任务。
- 不把“下一步”扩展成完整计划。
- 推荐理由必须来自确定性任务选择逻辑，不让 LLM 自己编造。
