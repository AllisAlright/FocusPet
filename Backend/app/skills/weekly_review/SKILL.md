## 技能定位

`weekly_review` 是 FocusPet 内部 Pet Agent Skill，不是 Codex 插件技能。

它只负责总结已经发生的专注记录，不给下一步任务安排，不做心理诊断，不评价用户自控力。

## 输入

- `stats`: 前端或后端已经汇总好的统计数据
- `pet_type`: 当前宠物类型，用于拼接宠物人设 prompt
- `period_days`: 复盘周期，默认 7 天

## 输出

严格返回：

```json
{
  "summary": "最近 7 天你专注了 4 次，累计 120 分钟。",
  "observation": "你主要在推进「论文开题」。",
  "pet_comment": "这些小段投入都已经留下来了。"
}
```

## 触发条件

明确触发：

- 用户说“复盘最近”
- 用户说“看看最近状态”
- 用户说“这周怎么样”
- 用户说“总结一下最近”

不触发：

- 用户询问下一步先做哪个
- 用户要求拆任务
- 用户只是闲聊
- 自伤、自杀、违法、暴力、危险、健康透支输入

## 执行流程

1. Pet Agent 先做安全审核。
2. 前端只传汇总统计，不上传完整历史内容。
3. API key 缺失或 LLM 请求失败时，使用 `fallback.py`。
4. 生成短复盘，返回结构化结果。
5. `pet_response_generator` 再包装成宠物最终说出口的话。

## 边界原则

- 不给下一步行动建议。
- 不生成压力型效率报告。
- 不评价用户自控力、人格或心理状态。
- 半夜专注较多时，只能温柔提醒休息。
- 只根据真实统计总结，不编造未提供的任务或记录。
